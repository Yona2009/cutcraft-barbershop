# CUTCRAFT — Premium Barbershop Landing Page

A modern premium barbershop landing page built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Premium dark neon UI
- Responsive layout
- Modern navbar with active section
- Cinematic hero section
- Services pricing cards
- Barbers showcase
- Gallery section
- Testimonials
- Booking modal popup
- Custom favicon
- Smooth scroll reveal

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
